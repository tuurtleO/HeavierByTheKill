HEAVIER BY THE KILL - QUICK START
=================================

Requirements:
- Windows 10 or 11, 64-bit
- Dark Souls Remastered app 1.03.1 / regulation 1.04 on Steam
- The game must be played OFFLINE while this mod is active

Install:
1. Extract the entire ZIP to a normal folder such as Downloads.
2. Double-click INSTALL MOD.cmd.
3. The installer finds your Steam library automatically. If it cannot, select
   the folder containing DarkSoulsRemastered.exe.

Play:
1. Start Dark Souls Remastered through Steam.
2. Choose Offline mode and load a character.
3. Double-click START MOD.cmd and leave its window open while playing.

Update:
- Extract the newer release and run INSTALL MOD.cmd again. Your settings and
  per-character progression are preserved.

Uninstall:
- Double-click UNINSTALL MOD.cmd. Progress is backed up beside the game before
  the mod folder is removed.

Troubleshooting:
- If Windows warns about an unrecognized app, verify the ZIP checksum shown on
  the GitHub release before choosing to run it.
- The installer intentionally refuses unsupported game executable versions.
- Do not run the mod online.

Full mechanics, configuration, OBS instructions, and technical limitations are
documented in README.md.
